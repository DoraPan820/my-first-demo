# 外企工业车辆（叉车/AGV）IoT项目管理技能
## 简介
本技能面向工业车辆团队项目管理，适配外企项目流程，覆盖电动叉车、AGV自动导引车车载物联网终端+云平台联合项目。
支持从项目立项、范围定义、里程碑管控、风险跟踪、变更管理，一直到项目交付收尾的完整项目管理流程。
适配行业品牌：永恒力、林德、丰田工业车辆项目场景。
重点覆盖IoT硬件项目特有管理项：硬件打样试产管理、固件OTA版本管控、物联卡资源管理、现场设备交付验收。

## 核心能力
- **项目立项管理**：项目章程、干系人分析、项目目标与边界
- **范围与需求管理**：WBS工作分解结构、需求跟踪矩阵RTM、需求基线管控
- **进度里程碑管理**：硬件/固件/云平台多模块联合排期，识别关键路径
- **风险与问题管理**：风险登记册、问题日志，硬件供应链、网络通信、固件BUG风险评估与应对预案
- **变更管理**：需求变更影响评估、变更审批流程
- **项目文档输出**：项目周报、会议纪要、项目评审清单、项目交付验收清单

## 使用方法
1. 把整套md文件导入豆包项目知识库
2. 在对话直接复制【项目管理快速指令清单.md】内指令，调用技能生成项目文档
3. 生成文档后，保存md文件，通过Git提交到本仓库做版本管理
